# Crypto Live Tracker

A full-stack cryptocurrency tracking application built with React, Node.js, Express.js, and MongoDB. 
The platform allows users to track real-time cryptocurrency prices, manage watchlists, and monitor investment portfolios through a modern and responsive interface.

##  Live Demo

Live: https://crypto-live-tracker.onrender.com

##  Features

* Real-time cryptocurrency market data
* User authentication and authorization
* Personalized watchlist management
* Portfolio tracking
* Secure REST APIs
* Responsive user interface
* MongoDB database integration

## Tech Stack

### Frontend

* React.js
* Vite
* React Router
* Axios

### Backend

* Node.js
* Express.js

### Database

* MongoDB
* Mongoose


## Installation

### Clone the repository

git clone https://github.com/KothakapuShivaRamReddy/crypto-live-tracker.git

### Install dependencies

npm install

### Run the application

npm run dev
